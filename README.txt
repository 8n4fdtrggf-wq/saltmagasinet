SALTMAGASINET – WEBBLEVERANS
============================

Innehåll
--------
index.html       Själva webbsidan
styles.css       All design och responsiv layout
script.js        Mobilmeny, header och mjuka animationer
assets/          Lokala bilder som används av sidan

Så förhandsvisas sidan
----------------------
Öppna index.html i en modern webbläsare. För slutlig publicering laddas hela
mappen upp oförändrad till webbhotellets publika rotmapp.

Kontrollerat 2026-09-29
-----------------------
Kontaktuppgifter, adress och öppettider är hämtade från saltmagasinet.com.
Kontrollera alltid öppettider, bokningslänk och meny med restaurangen innan
publicering eftersom dessa kan ändras.

Bilder
------
Bilderna i assets/ är AI-genererade för detta designförslag och är inte foton
av den faktiska restaurangen eller dess rätter. Byt gärna till kundens egna
professionella bilder före skarp publicering. Filnamnen kan behållas för att
slippa ändra HTML-koden.

Typsnitt
--------
Sidan använder Italiana och DM Sans från Google Fonts. Om sidan ska fungera
helt utan internet behöver typsnitten laddas ner och bäddas in lokalt.

Teknik
------
Sidan är vanlig HTML, CSS och JavaScript utan byggsteg eller ramverk. Den är
responsiv och fungerar på mobil, surfplatta och dator.
